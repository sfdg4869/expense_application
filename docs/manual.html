경비신청서 만들기

카드 사용내역 + 회사 양식 + 영수증 → 제출용 엑셀을 자동으로 만드는 프로그램

1. 프로그램 폴더

배포받은 경비신청서 프로그램 폴더를 엽니다.
아래 파일들이 같은 폴더에 있어야 합니다.

📄 경비만들기.vbs ← 이걸 실행 📄 경비만들기.bat 📁 docs 📁 scripts

이 설명서 위치: 프로그램 폴더 안 docs\manual.html
(지금 보고 계신 파일입니다. 바탕화면 바로가기를 만들어 두면 편합니다.)

※ scripts 폴더와 그 안의 파일은 프로그램이 자동으로 사용합니다. 직접 수정하거나 삭제하지 마세요.

2. 실행 방법

✅ 권장 — 경비만들기.vbs

  1. 프로그램 폴더를 탐색기로 엽니다.
  2. 경비만들기.vbs 를 더블클릭합니다.
  3. 「경비신청서 만들기」 창이 뜨면 성공입니다.

대안 — 경비만들기.bat

경비만들기.bat 더블클릭해도 같은 프로그램이 실행됩니다.
(검은 명령 창이 잠깐 보일 수 있습니다. 경비만들기.vbs 가 더 깔끔합니다.)

필요한 환경
Windows10 이상
Microsoft ExcelPC에 설치되어 있어야 합니다
실행 전에 열려 있는 엑셀 파일을 모두 닫아 주세요.

5. 사용 순서

1
카드 사용내역 선택
「찾기」 → 카드사에서 받은 명세서 엑셀 선택
→ 아래 표에 거래 목록이 나타납니다.
2
회사 양식 선택
「찾기」 → 제경비 신청 양식 엑셀 선택
3
후불교통비 넣기 (있을 때만)
「찾기」 → 현대카드 MY COMPANY에서 받은 후불교통 이용내역 선택
택시·고속버스 내역은 자동으로 제외됩니다.
4
영수증 넣기 (있을 때만)
「폴더」 — 영수증이 모인 폴더 선택
「파일」 — 사진을 직접 여러 장 선택
5
기본값 확인
항목설명예시
계정엑셀에 들어갈 계정복리후생비
거래처거래처명엑셈
사용자본인 이름홍길동
업무상세경비 구분야근식대
부서저장 파일명에 들어갈 부서명제품기술연구
한 번 입력해 두면 다음에도 자동으로 불러옵니다.
6
거래 목록 — 행별 경비 유형 설정
  • 명세서를 불러오면 기본값(예: 야근식대)이 모든 행에 들어갑니다. 경비 종류마다 프리셋을 적용해야 금액이 올바르게 계산됩니다.
  • 경비 유형 프리셋 선택 → 해당 행 클릭(여러 행 선택 가능) → 「선택 행에 적용」
  • 표에서 계정 · 업무상세 열을 직접 수정해도 됩니다. 수정하면 개인사용 금액이 자동으로 다시 계산됩니다.
  • 상단 기본값으로 여러 행을 한꺼번에 넣으려면 「기본값 일괄 적용」
  • 개인사용 열 — 프로그램이 자동 계산 (직접 입력 불가)
  • 동행자 — 식대일 때만 (쉼표 구분, 인원 자동 반영)
  • 증빙 열에 「필요」 — 편의점·마트·커피 등, 영수증 첨부 권장
택시·주유 등은 반드시 「택시」「주유」 프리셋을 적용하세요.
기본값(야근식대)이 그대로 남아 있으면 식대 규칙(12,000원 한도)이 적용될 수 있습니다.
7
「완성 엑셀 만들기」 클릭
  1. 저장할 위치와 파일 이름을 정합니다.
  2. 「저장」을 누르면 엑셀이 자동으로 작성됩니다. (잠시 기다림)
  3. 「완료」 메시지가 뜨면 끝입니다.
버튼 오른쪽 합계 표에 금액이 표시됩니다.
숫자를 드래그한 뒤 Ctrl+C 로 복사할 수 있습니다.

한 달 명세서에 식대·택시·사무용품 등이 섞여 있어도, 거래마다 계정과 업무상세를 다르게 넣을 수 있습니다.

택시여비교통비택시택시·대리 이용 행에 적용

개인사용선급금개인사용회사 경비가 아닌 개인 결제 행에 적용

프리셋 목록은 scripts\expense-presets.json 에서 회사 기준에 맞게 추가·수정할 수 있습니다.

팁: Ctrl 키를 누른 채로 여러 행을 선택한 뒤, 프리셋을 한 번에 적용할 수 있습니다.

8. 식대 규칙 (상세)

업무상세가 「~식대」 로 끝나는 프리셋(야근식대, 주말식대, 출장식대, 점심식대 등)에만 아래 규칙이 적용됩니다.

1인 한도12,000원
인원 계산본인 1명 + 동행자 수 (동행자 칸에 이름을 쉼표로 구분해 입력)
2명이 같이 먹으면한도 24,000원 (12,000 × 2명)
한도를 넘으면넘은 금액만 개인사용으로 잡힘
인원 직접 수정「인원」 열을 직접 바꿀 수도 있습니다

예시) 1명 · 13,500원 → 경비신청 12,000원 / 개인사용 1,500원
예시) 2명 · 23,600원 → 경비신청 23,600원 / 개인사용 0원
예시) 동행자 「김철수, 이영희」· 35,000원 → 인원 3명 · 한도 36,000원 → 경비신청 35,000원 / 개인사용 0원

9. 증빙 필요 안내

편의점(GS25, CU), 마트, 커피 전문점, 배달 앱, 쇼핑몰 등은 회사 규정상 영수증 첨부가 필요합니다.

  • 거래 표 「증빙」 열에 필요 로 표시됩니다.
  • 영수증 개수가 부족하면 완성 전 경고가 뜹니다.
  • 영수증은 파일명 순으로 지출증빙 시트에 들어갑니다. (첨부파일(1) 4칸 → 첨부파일(2) 4칸)

10. 후불교통비 (선택)

후불 교통카드·하이패스 이용내역은 카드 명세서와 별도 파일입니다.

  1. 「후불교통비 내역」에서 엑셀 선택
  2. 택시·고속버스는 자동 제외
  3. 완성 엑셀의 후불교통비명세서 시트에 입력

합계 표에는 카드 이용내역 + 교통비가 함께 반영됩니다.

11. 완성 후

지정한 위치에 .xls 파일이 생성됩니다.

파일 이름 예시:

(카드)제경비신청서_4월_제품기술연구_홍길동.xls

엑셀 안에 자동으로 채워지는 내용

1. 이용내역명세서카드 거래 내역 + 행별 계정·업무상세·경비신청금액·개인사용금액
후불교통비명세서교통비 내역 (선택 시)
1-1. 지출증빙 첨부영수증 사진 (시트당 8장: 첨부파일(1) 4장 + 첨부파일(2) 4장, 많으면 시트 추가)
마지막 단계: 완성된 .xls 파일을 사내 경비 신청 포털에 업로드하세요.

12. 자주 묻는 문제

택시인데 개인사용이 나와요 해당 행을 선택한 뒤 프리셋에서 「택시」를 고르고 「선택 행에 적용」을 누르세요.
업무상세가 「야근식대」 등 식대로 남아 있으면 12,000원 한도가 적용됩니다. 택시는 금액과 관계없이 개인사용 0원이어야 합니다.
개인사용 칸을 수정할 수 없어요 정상입니다. 개인사용은 경비 유형에 따라 자동 계산되며 직접 입력할 수 없습니다.
금액이 맞지 않으면 해당 행의 프리셋(업무상세)을 확인하세요.
엑셀 작성이 실패해요 열려 있는 엑셀을 모두 닫고 다시 시도하세요.
프로그램이 안 열려요 PC에 Excel이 설치되어 있는지 확인하세요.
경비만들기.vbs 가 있는 폴더 전체가 옮겨졌는지 확인하세요. (scripts 폴더 필수)
영수증이 안 들어가요 jpg, png 형식인지 확인하고 「폴더」 또는 「파일」로 다시 선택하세요.
입력값이 다음에도 남아요 정상입니다. 계정·거래처·부서 등은 자동 저장됩니다.
한 달에 경비 종류가 여러 개예요 거래 표에서 행마다 프리셋을 적용하거나, 계정·업무상세를 직접 수정하세요.
증빙 필요라고 나와요 편의점·마트 등은 영수증을 폴더/파일로 추가하세요. 파일명 순으로 첨부됩니다.
교통비 시트가 없다고 해요 회사 양식에 「후불교통」 시트가 있는지 확인하세요.
