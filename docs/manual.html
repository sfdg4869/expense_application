경비신청서 만들기

카드 사용내역 + 회사 양식 + 영수증 → 제출용 엑셀을 자동으로 만드는 프로그램

빠른 시작 (3단계)
  1. 프로그램 폴더에서 경비만들기.vbs 더블클릭

  3. 완성 엑셀 만들기 → 저장 위치 지정 → 완료

1. 프로그램 폴더

배포받은 경비신청서 프로그램 폴더를 엽니다.
아래 파일들이 같은 폴더에 있어야 합니다.

📄 경비만들기.vbs ← 이걸 실행 📄 경비만들기.bat 📁 docs 📁 scripts

이 설명서 위치: 프로그램 폴더 안 docs\manual.html
(지금 보고 계신 파일입니다. 바탕화면 바로가기를 만들어 두면 편합니다.)

※ scripts 폴더와 그 안의 파일은 프로그램이 자동으로 사용합니다. 직접 수정하거나 삭제하지 마세요.

2. 실행 방법

✅ 권장 — 경비만들기.vbs

  1. 프로그램 폴더를 탐색기로 엽니다.
  2. 경비만들기.vbs 를 더블클릭합니다.
  3. 「경비신청서 만들기」 창이 뜨면 성공입니다.

대안 — 경비만들기.bat

경비만들기.bat 더블클릭해도 같은 프로그램이 실행됩니다.
(검은 명령 창이 잠깐 보일 수 있습니다. 경비만들기.vbs 가 더 깔끔합니다.)

필요한 환경
Windows10 이상
Microsoft ExcelPC에 설치되어 있어야 합니다
실행 전에 열려 있는 엑셀 파일을 모두 닫아 주세요.

3. 미리 준비할 것

파일어디서 받나요
필수 카드 사용내역
.xls 또는 .xlsx		 카드사 홈페이지에서 다운로드한 이용내역 명세서
필수 회사 양식
.xls 또는 .xlsx		 사내 제경비 신청 양식
예: (카드)제경비신청서_4월_부서_성명.xls
선택 영수증 사진
jpg, png 등		 폴더 통째로 또는 파일 여러 개 선택
영수증은 파일 이름 순서대로 엑셀에 들어갑니다.
순서를 맞추려면 파일명 앞에 01_, 02_ 처럼 번호를 붙이세요.

5. 사용 순서

1
카드 사용내역 선택
「찾기」 → 카드사에서 받은 명세서 엑셀 선택
→ 아래 표에 거래 목록이 나타납니다.
2
회사 양식 선택
「찾기」 → 제경비 신청 양식 엑셀 선택
3
영수증 넣기 (있을 때만)
「폴더」 — 영수증이 모인 폴더 선택
「파일」 — 사진을 직접 여러 장 선택
4
기본값 확인
항목설명예시
계정엑셀에 들어갈 계정복리후생비
거래처거래처명엑셈
사용자본인 이름홍길동
업무상세경비 구분야근식대
부서저장 파일명에 들어갈 부서명제품기술연구
한 번 입력해 두면 다음에도 자동으로 불러옵니다.
5
거래 목록 확인 · 수정 (필요할 때)
  • 동행자 — 같이 식사한 사람 (쉼표로 구분: 김철수, 이영희)
  • 인원 — 식사 인원 수 (동행자 입력 시 자동 계산)
  • 개인사용 — 야근식대 한도 초과분 (자동 계산)
6
「완성 엑셀 만들기」 클릭
  1. 저장할 위치와 파일 이름을 정합니다.
  2. 「저장」을 누르면 엑셀이 자동으로 작성됩니다. (잠시 기다림)
  3. 「완료」 메시지가 뜨면 끝입니다.
버튼 오른쪽 합계 표에 금액이 표시됩니다.
숫자를 드래그한 뒤 Ctrl+C 로 복사할 수 있습니다.

6. 야근식대 규칙

업무상세가 「야근식대」일 때만 적용됩니다.

1인 한도12,000원
2명이 같이 먹으면한도 24,000원 (12,000 × 2명)
한도를 넘으면넘은 금액이 개인사용으로 잡힘

예시) 1명이 13,500원 사용 → 경비신청 12,000원 / 개인사용 1,500원
예시) 2명이 23,600원 사용 → 경비신청 23,600원 / 개인사용 0원

7. 완성 후

지정한 위치에 .xls 파일이 생성됩니다.

파일 이름 예시:

(카드)제경비신청서_4월_제품기술연구_홍길동.xls

엑셀 안에 자동으로 채워지는 내용

1. 이용내역명세서카드 거래 내역 + 계정·거래처·사용자·경비금액
1-1. 지출증빙 첨부영수증 사진 (8장씩, 많으면 시트 추가)
마지막 단계: 완성된 .xls 파일을 사내 경비 신청 포털에 업로드하세요.

8. 자주 묻는 문제

엑셀 작성이 실패해요 열려 있는 엑셀을 모두 닫고 다시 시도하세요.
프로그램이 안 열려요 PC에 Excel이 설치되어 있는지 확인하세요.
경비만들기.vbs 가 있는 폴더 전체가 옮겨졌는지 확인하세요. (scripts 폴더 필수)
영수증이 안 들어가요 jpg, png 형식인지 확인하고 「폴더」 또는 「파일」로 다시 선택하세요.
입력값이 다음에도 남아요 정상입니다. 계정·거래처·부서 등은 자동 저장됩니다.
합계 표가 안 보여요 프로그램을 완전히 닫고 경비만들기.vbs 로 다시 실행하세요.
